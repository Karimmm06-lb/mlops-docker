# 🚀 Roadmap ML / AI Engineer

> Parcours d'apprentissage vers une alternance **Machine Learning / AI Engineer**.
> Objectif : maîtriser le cycle complet, du fondamental au déploiement (MLOps), et construire un portfolio de projets déployés.

---

## 🎯 Objectif final

Devenir **AI Engineer** capable de construire, entraîner **et déployer** des modèles ML/LLM en production, avec une vraie culture MLOps.

---

## 🗺️ Vue d'ensemble

| Phase | Thème | Durée estimée | Statut |
|-------|-------|---------------|--------|
| 1 | Fondations (Python, maths, Git) | 1–2 mois | ⬜ |
| 2 | Machine Learning classique | 2–3 mois | ⬜ |
| 3 | Deep Learning & LLMs | 2–3 mois | ⬜ |
| 4 | MLOps | En continu | 🟡 En cours |
| 5 | Cloud & Certification | 3–6 mois | ⬜ |
| 6 | Portfolio & Alternance | En continu | ⬜ |

---

## 📚 Phase 1 — Fondations *(1–2 mois)*

- [ ] **Python** : numpy, pandas, matplotlib
- [ ] **Maths appliquées** : algèbre linéaire, probabilités/statistiques, calcul différentiel
- [ ] **Git / GitHub** : commits, branches, pull requests
- [ ] **Ligne de commande Linux** de base

---

## 🤖 Phase 2 — Machine Learning classique *(2–3 mois)*

- [ ] **scikit-learn** : régression, classification, clustering
- [ ] Modèles clés : régression logistique, arbres, Random Forest, **XGBoost**
- [ ] Workflow complet : préparation → entraînement → validation croisée → métriques
- [ ] Comprendre **overfitting / underfitting** et la régularisation
- [ ] 🎯 **Projet** : 2–3 projets end-to-end sur Kaggle

---

## 🧠 Phase 3 — Deep Learning & LLMs *(2–3 mois)*

- [ ] **PyTorch** (ou TensorFlow) : réseaux de neurones
- [ ] **CNN** (vision) et **Transformers** (NLP)
- [ ] **LLMs** : embeddings, RAG, prompt engineering, fine-tuning
- [ ] Outils : Hugging Face, LangChain
- [ ] 🎯 **Projet** : une application avec un LLM (chatbot RAG, assistant…)

---

## ⚙️ Phase 4 — MLOps *(en continu)* 🟡

- [x] **Docker** — conteneurisation d'un modèle
- [x] **Git / GitHub** — versionning du projet `mlops-docker`
- [ ] **CI/CD** avec GitHub Actions (build auto à chaque push) ⬅️ *prochaine étape*
- [ ] **API modèle** avec FastAPI
- [ ] **Tracking d'expériences** avec MLflow
- [ ] **Monitoring** du modèle en production
- [ ] Déploiement cloud

---

## ☁️ Phase 5 — Cloud & Certification *(3–6 mois)*

- [ ] Choisir un cloud : **AWS** (recommandé) ou **GCP**
- [ ] **IBM AI Engineering Professional Certificate** (Coursera)
- [ ] **AWS Certified Machine Learning Engineer – Associate**
- [ ] *(alternative)* **Google Cloud Professional Machine Learning Engineer**

---

## 🏆 Phase 6 — Portfolio & Alternance *(en continu)*

- [ ] 3–4 projets **déployés et publics** sur GitHub
- [ ] Au moins 1 projet avec un **LLM / RAG**
- [ ] README soigné pour chaque projet
- [ ] CV + LinkedIn à jour
- [ ] Candidatures alternance

---

## 🛠️ Stack visée

**Langage** : Python
**ML** : scikit-learn, XGBoost
**Deep Learning** : PyTorch, Hugging Face
**MLOps** : Docker, GitHub Actions, FastAPI, MLflow
**Cloud** : AWS (SageMaker) *ou* GCP (Vertex AI)
