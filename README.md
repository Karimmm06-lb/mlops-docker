# 🚀 MLOps Docker — Projet d'apprentissage

Ce repo est la **première étape de mon roadmap MLOps** que je construis en 6 semaines intensives pour décrocher une alternance en tant qu'**Ingénieur MLOps**.

## 🎯 Objectif

Partir de zéro sur les technologies MLOps et construire un **pipeline complet de bout en bout** : de l'entraînement d'un modèle ML jusqu'à son déploiement en production, avec monitoring.

## 🗺️ Ce que je vais accomplir

### ✅ Phase 1 — Docker & CI/CD *(en cours)*
- Conteneurisation d'applications avec Docker
- Orchestration multi-services avec Docker Compose
- Pipelines CI/CD avec GitHub Actions

### 🔜 Phase 2 — Bases Data Science & Machine Learning
- Manipulation de données avec pandas & numpy
- Entraînement de modèles avec scikit-learn
- Évaluation et métriques (accuracy, F1, AUC)

### 🔜 Phase 3 — Outils MLOps
- Tracking d'expériences avec **MLflow**
- Versioning des données avec **DVC**
- Déploiement d'API ML avec **FastAPI**

### 🔜 Phase 4 — Cloud AWS
- Déploiement sur EC2
- Stockage de modèles sur S3
- Gestion des accès avec IAM

### 🔜 Phase 5 — Kubernetes & Monitoring
- Orchestration de conteneurs avec **Kubernetes** (minikube)
- Monitoring des modèles en production avec **Weights & Biases**

### 🔜 Phase 6 — Projet Final
Pipeline MLOps complet :
```
Données (DVC) → Entraînement (MLflow) → API FastAPI → CI/CD GitHub Actions → K8s → Monitoring W&B
```

## 🛠️ Stack actuelle

| Catégorie | Technologies |
|-----------|-------------|
| Conteneurisation | Docker, Docker Compose |
| CI/CD | GitHub Actions |
| ML | scikit-learn, pandas, numpy |
| MLOps | MLflow, DVC, Weights & Biases |
| Cloud | AWS (EC2, S3) |
| Orchestration | Kubernetes |
| Backend | FastAPI, Flask |

Étudiant ingénieur en cycle prépa à CESI, je me forme en autonomie sur les technologies MLOps pour devenir **ingénieur IA** et décrocher une alternance en 2026/2027.

Ce repo documente ma progression semaine par semaine.
